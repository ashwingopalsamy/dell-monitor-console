# Support

- Question or bug → [open an issue](https://github.com/ashwingopalsamy/dell-monitor-console/issues/new/choose).
  Include the app version (Finder › Get Info) and, for display problems, the output of `DellMonitorConsole --list`.
- Input switching, presets, KVM or firmware → use Dell's own app. This app only sets brightness.
- This is a hobby project. Not affiliated with, endorsed by or supported by Dell.
